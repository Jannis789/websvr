Available on (crate features proxy or haproxy or socks5) and crate feature proxy only.
Expand description

The trait to implement to provide a proxy database to other facilities, such as connection pools, to provide a proxy based on the given [TransportContext] and ProxyFilter.

Required Associated Types§

Source

type Error: Send + 'static

The error type that can be returned by the proxy database

Examples are generic I/O issues or even more common if no proxy match could be found.

Required Methods§

Source

fn get_proxy_if( &self, ctx: ProxyContext, filter: ProxyFilter, predicate: impl ProxyQueryPredicate, ) -> impl Future<Output = Result<Proxy, Self::Error>> + Send

Same as Self::get_proxy but with a predicate to filter out found proxies that do not match the given predicate.

Provided Methods§

Source

fn get_proxy( &self, ctx: ProxyContext, filter: ProxyFilter, ) -> impl Future<Output = Result<Proxy, Self::Error>> + Send

Get a Proxy based on the given ProxyContext and ProxyFilter, or return an error in case no Proxy could be returned.

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety", so this trait is not object safe.
