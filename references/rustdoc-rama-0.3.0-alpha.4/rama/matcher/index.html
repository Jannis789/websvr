Matcher utilities for any middleware where need to match on incoming inputs.

This module provides the Matcher trait and convenience utilities around it.

  • Examples of this are iterator “reducers” as made available via IteratorMatcherExt, as well as optional Matcher::or and Matcher::and trait methods.
  • These all serve as building blocks together with And, Or, Not and a bool to combine and transform any kind of Matcher.
  • And finally there is MatchFn, easily created using match_fn to create a Matcher from any compatible Fn.
