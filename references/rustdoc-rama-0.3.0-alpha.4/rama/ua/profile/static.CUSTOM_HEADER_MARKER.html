Marker header name for custom headers.

Header value: x-rama-custom-header-marker

This is used to identify in the HttpHeadersProfile the initial location of custom headers, which is also by the [UserAgentEmulateRequestModifier] used to place any original request headers that were not present in the HttpHeadersProfile (also called base headers).

If this header is not present in the HttpHeadersProfile then it will be assumed that remaining headers are to be put as the final headers in the request header map.
