Function pending 

Source 
pub fn pending<T>() -> Pending<T> ⓘ
Expand description

Creates a future which never resolves, representing a computation that never finishes.

The returned future will forever return Poll::Pending.

§Examples

ⓘ
use futures::future;

let future = future::pending();
let () = future.await;
unreachable!();
