Struct MutexGuard 

Source 
pub struct MutexGuard<'a, T>
where
    T: ?Sized,
{ /* private fields */ }
Available on crate feature alloc only.
Expand description

An RAII guard returned by the lock and try_lock methods. When this structure is dropped (falls out of scope), the lock will be unlocked.

pub fn map<U, F>(this: MutexGuard<'a, T>, f: F) -> MappedMutexGuard<'a, T, U>
where F: FnOnce(&mut T) -> &mut U, U: ?Sized,

Returns a locked view over a portion of the locked data.

§Example
use futures::lock::{Mutex, MutexGuard};

let data = Mutex::new(Some("value".to_string()));
{
    let locked_str = MutexGuard::map(data.lock().await, |opt| opt.as_mut().unwrap());
    assert_eq!(&*locked_str, "value");
}
